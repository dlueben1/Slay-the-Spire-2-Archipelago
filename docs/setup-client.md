# Installation

To play the Slay the Spire II Archipelago Randomizer, you'll need the following:

## Slay the Spire II

This one is probably obvious, but you'll need the Steam Version of Slay the Spire II, which can be [bought here](https://store.steampowered.com/app/2868840/Slay_the_Spire_2/).

> [!CAUTION]
> We do not condone piracy, and will not provide support for people running illegal versions of the game.

## RitsuLib

RitsuLib is a dependency library that makes it easier for mods like ours to integrate with Slay the Spire II. It's similar to BaseLib, if you're familiar with it.

You'll find it [on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295), and it should keep itself up-to-date automatically once you subscribe to it.

## The Slay the Spire II Archipelago Mod

Finally, you'll need the Archipelago mod for Slay the Spire II, which can be found [on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3748826296).

> [!NOTE]
> Archipelago Launcher is not required to play the Slay the Spire II Archipelago Mod, only for generating/hosting games with it.

# Create your YAML file

A YAML file tells Archipelago what settings you'd like to use. This allows you to configure your experience by controlling what is randomized, what's shuffled into the Multiworld pool, and how certain features and items should behave.

**The easiest and recommended way to do this is to use the YAML Builder**, which can be accessed on our [official website](/#/builder), or by selecting "Create Player YAML" on the in-game main menu.

Otherwise, you can create the YAML file manually or using the Archipelago Launcher's "Options Creator".

> [!TIP]
> For more information on configuring YAML files, please visit the official [Archipelago website](https://archipelago.gg/tutorial/Archipelago/advanced_settings_en)

# Connecting to an Archipelago Session

Once you've subscribed to both of those mods, start Slay the Spire II. If the mod is working properly, you'll notice that the entire Main Menu has been overhauled, and there should be an option called "Connect".

To join an Archipelago session, click "Connect", then fill in the information prompted to begin playing.

> [!CAUTION]
> While playing the Slay the Spire II Archipelago mod, please disable any mods that are **not** being used by the randomizer (i.e. every mod that isn't RitsuLib, Slay the Spire II Archipelago, and any custom characters you've configured). These may cause the mod to break, or behave unexpectedly.

> [!WARNING]
> While we have support for custom (modded) characters, we cannot guarantee that all custom characters will work. Please use this feature at your own risk, and test a practice game in advance to ensure that the custom characters you've chosen do not break the Archipelago mod.
