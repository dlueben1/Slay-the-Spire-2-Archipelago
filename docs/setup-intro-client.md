# Getting Started

This guide will walk you through setting up the Slay the Spire II Archipelago Mod, and connecting to an Archipelago session.

> [!WARNING]
> While we have experimental support for the "Beta" branch of Slay the Spire II, it changes often and can break easily. It's recommended to use the "Default Public Version" when playing, as it's the main version we can guarantee compatibility with, and the version we expect you to use in this guide.
