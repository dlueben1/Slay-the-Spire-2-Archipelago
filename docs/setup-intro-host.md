# Getting Started

This guide will walk you through setting up an Archipelago Randomizer game with your friends, where at least one player is playing Slay the Spire II.

> [!TIP]
> The [setup guide on GitHub](https://github.com/dlueben1/Slay-the-Spire-2-Archipelago/blob/setup-docs-do-not-delete/world/spire2/docs/setup_en.md) is the most up-to-date version of these instructions. This page can lag behind it.

> [!NOTE]
> These steps are only needed by the person setting up the game. If you're just trying to connect to an existing Archipelago session with Slay the Spire II, [follow these steps instead](/#/setup/client).
