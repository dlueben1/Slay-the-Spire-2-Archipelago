# Modded Characters

The Archipelago mod can randomize modded characters alongside the game's own. Add them in the [YAML Builder](/#/builder)'s Character Setup step, or in your YAML's `modded_characters` list, and install each character's mod before you play.

This page covers how to name a character in your YAML, what to do when a character mod breaks, and the characters that have ready-made names.
