# Finding a modded character ID

The wizard needs a modded character's **internal ID**, which may be different from the name shown on its Steam Workshop page.

1. Start Slay the Spire II with the character mod and the Archipelago mod installed.
2. Open **Archipelago Settings** in the game.
3. Select **Archipelago** to view the installed modded character IDs.
4. Copy the exact ID into the matching wizard row.

> [!IMPORTANT]
> Character IDs are case-sensitive configuration values. Each row must use a unique ID, and the matching character mod must be installed when you play.

If a configured character mod is unavailable, its checks can still be sent while another character is played. If none of the configured modded characters are installed, the game falls back to a limited Ironclad experience.
