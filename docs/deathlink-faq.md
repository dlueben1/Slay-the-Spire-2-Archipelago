# What is Death Link?

## Overview

Death Link is an Archipelago Setting that makes it so when one player in your Archipelago Session dies, everyone with Death Link on also dies.

To send and receive Death Link triggers, you must opt-in to this system.

If you change your mind at any point while playing the game, you can use the "Archipelago Settings" in-game to turn this feature on or off manually.

## Death Link & Slay the Spire 2

While some games have frequent deaths - like Celeste - Slay the Spire 2 is a game where death is run-ending, and dying is infrequent. So, Death Link has interesting interactions with this game.

Instead of killing you immediately anytime someone dies - which is sure to keep you from making any progress if you're playing with a lot of friends - there are a number of different options you can choose from that can happen to you when a Death Link trigger is received.
