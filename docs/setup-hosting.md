# Step 2: Hosting the Archipelago Session

Now that you've generated your Archipelago session, you need to host it somewhere so that people can play! There are two options for this.

## Option 1: Archipelago's Official Website (Recommended)

The easiest way to host an Archipelago session is to let the official website do it for you. That way it's running 24/7 and no one needs to configure their network settings or leave a computer on for others to play.

Doing this is incredibly simple once you've generated your session.

1. Go to the official Archipelago website and click ["Start Playing"](https://archipelago.gg/start-playing)
1. Click the link at the **bottom** that says "host a pre-generated game for you"
1. Click "Upload File" and select the `.zip` file that we generated in the previous step
1. Click "Create new Room"

This is now a live lobby for connecting everyone to the Archipelago session.

While some games will require players to install Patch files or even the Archipelago Launcher itself, anyone playing Slay the Spire II simply needs to follow the instructions found on our [website](/#/setup/client).

## Option 2: Hosting it Locally

If you desire, you can also host the game locally. For more information on this, visit the [official Archipelago website](https://archipelago.gg/tutorial/Archipelago/setup_en).
